# Fix side pot label disappearing on all-in from player action — 20260322.1616

## Summary
Fixed a bug where side pot labels disappeared when the last player went all-in during their action (e.g., StackSniper going all-in making everyone all-in). The `onPlayerAction` all-in detection path set `allInRunout = true` but never froze the pot label with the side pot breakdown, unlike the `advanceGame` path which correctly snapshots and freezes the pot display using `computeSidePots`. Added the same pot-freezing logic to the `onPlayerAction` path.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — added pot label freezing with `computeSidePots` in the `onPlayerAction` all-in detection block (after `allInRunout = true`)
