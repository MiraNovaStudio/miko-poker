# Fix knockout animation timing — fire after all pot awards complete — 20260322.1751

## Summary
The knockout animation was firing at the same time as pot award animations, causing them to be visually buried. Moved `checkForEliminatedPlayers` from running synchronously in `onHandComplete` to running after a delay of `extraDelay + 1800ms` (after all pot fly animations land). This ensures the knockout animation (cards fly to center, avatar spins off screen, K.O. label) plays clearly after the pot has been shipped to the winner.

Also adjusted downstream timing:
- Game-over modal now triggers 3s after knockout fires
- Next hand delay increased from 8s to 10s to give knockout animation + K.O. label time
- Card dimming and hand name skips now use `player.chips <= 0` instead of `eliminatedPlayers.has()` since the set isn't populated until the delayed check
