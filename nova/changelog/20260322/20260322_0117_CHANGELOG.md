# Add pause functionality with P key — 20260322.0117

## Summary
Press P to pause/unpause the game. When paused, a semi-transparent "PAUSED" overlay appears (45% opacity so the board, stacks, and pot labels are still visible for screenshots). All game timers are frozen — delayed callbacks are queued and replayed when unpaused. Pause state is cleared on restart/quit.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `_paused` flag, `_pausedQueue`, pause overlay, `togglePause()`/`pause()`/`unpause()` methods; `delayed()` queues callbacks when paused; `resetDebugState()` auto-unpauses
- **miko-ui/src/main.ts** — Added P keydown listener that calls `togglePause()` on the active game scene (skipped when typing in inputs)
