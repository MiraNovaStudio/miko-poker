# Fix ALL IN label not clearing when uncalled bet is returned — 20260322.0131

## Summary
When a player goes all-in for more than any opponent can match, the engine returns the excess chips and sets `allIn = false`. But the UI wasn't refreshing chip labels at that point, so the ALL IN label stayed even though the player had chips back. Fixed by calling `updateAllChipLabels()` on both `street_changed` and `pot_updated` events, which catches the moment `collectBets` returns uncalled bets.
