# Fix side pot display disappearing on street changes and math errors — 20260322.0016

## Summary
Fixed two issues with the side pot label display:

1. **Side pot disappearing on street change**: The UI's `computeSidePots()` calculated pot amounts from `totalBet` values independently from the engine's actual pot total. On street transitions, the computed amounts could diverge from reality, causing the side pot to vanish or show wrong numbers.

2. **Math not adding up**: Main + Side pot amounts didn't always equal the total pot because the UI calculation was independent of the engine's `getCurrentPot()`.

Fixed by scaling the computed pot breakdown so Main + Side always sum to the engine's real total pot. Also added detection for implicit side pots when `computeSidePots` returns only one layer but there's money above the all-in level.
