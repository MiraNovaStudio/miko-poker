# Fix side pot layer calculation with partial contributions — 20260322.0046

## Summary
The side pot display was creating phantom extra side pots because the calculation used `level × numContributors` which doesn't account for players who bet between two all-in levels (partial contributions). For example, a $728 bet into a $803 all-in level was left as a "remainder" shown as its own side pot.

Rewrote the pot layer calculation to sum each player's actual contribution at each boundary level: `min(totalBet, boundary) - min(totalBet, prevBoundary)`. This correctly distributes partial bets into the appropriate pot layer. With 3 all-in levels ($12, $803, $1000), the display now correctly shows Main + 2 Side pots.
