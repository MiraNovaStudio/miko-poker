# Fix game freeze — allInRunout not reset between hands — 20260322.1822

## Summary
Fixed a game freeze caused by the `allInRunout` flag not being reset at the start of each new hand. If a previous hand had an all-in runout, the flag would carry over. In the next hand, if the `advanceGame` loop detected an all-in condition (`allOpponentsAllIn`), it would see `allInRunout` was already `true`, skip the `forceHandComplete` call, and return — permanently killing the game loop.

Added resets for `allInRunout`, `_foldWinDeferred`, `streetQueue`, and `pendingHandResult` in `onHandStarted()` to ensure a clean state at the start of every hand.
