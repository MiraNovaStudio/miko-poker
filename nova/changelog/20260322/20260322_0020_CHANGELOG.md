# Skip loading card PNGs when using Unicode deck — 20260322.0020

## Summary
The AssetManager was loading all 52 card face PNGs at startup regardless of the deck type setting. On a t2.micro this added unnecessary load time and 52 wasted HTTP requests for Unicode deck users. Now card PNGs are only loaded if the user's saved deck setting is PNG. If they switch to PNG mid-game via settings, the PNGs are loaded on demand.

## Files Changed

### Modified
- **miko-ui/src/managers/AssetManager.ts** — Check `SettingsManager.deckType` before loading card PNGs; added `loadCardPngs()` method for on-demand loading
- **miko-ui/src/main.ts** — Call `AssetManager.loadCardPngs()` when user clicks PNG deck button in settings
