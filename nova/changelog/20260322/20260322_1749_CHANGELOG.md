# Fix losing hand label on top row using same large style as winner — 20260322.1749

## Summary
Top-row losing players' hand names (e.g. "Pair of Sixes") were displayed using the same large 32px bold gold text as the winner's hand name, making them visually indistinguishable. Added a separate `showLosingHandAtSlot` method with smaller (16px), muted gray text and a simple fade-in instead of the elastic bounce animation. Non-top-row losers already used the small italic bet label style.

### Modified
