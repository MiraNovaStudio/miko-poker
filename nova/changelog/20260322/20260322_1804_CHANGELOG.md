# Fix game-over sound and avatar size during knockout — 20260322.1804

## Summary
Two fixes for the knockout animation:

1. **Game-over sound not playing**: Since `checkForEliminatedPlayers` was moved to a delayed callback (after pot awards), the player wasn't in the `eliminatedPlayers` set when the pot award code checked for it. Moved the game-over sound to play inside `checkForEliminatedPlayers` when the player is detected as eliminated, right at the start of the knockout animation.

2. **Avatar shrinking**: The avatar spin animation was scaling the avatar down to 50% (`1 - ease * 0.5`). Removed the scale reduction so the avatar maintains its full size while spinning off screen.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — play game-over sound inside `checkForEliminatedPlayers` when player is eliminated
- **miko-ui/src/components/PlayerSlot.ts** — removed avatar scale reduction from knockout spin animation
