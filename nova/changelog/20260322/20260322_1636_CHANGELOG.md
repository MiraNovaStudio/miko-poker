# Fix side pot labels pushing chips off screen — 20260322.1636

## Summary
Redesigned pot label layout so side pots grow downward instead of upward. Previously, multi-line pot labels (Main + Side pots) expanded upward from center, pushing the chip stack off the top of the screen. Now the pot label anchor is top-center so:
- Chip stack stays at a fixed position above the pot label (never moves)
- Main pot label stays at a fixed position
- Side pot labels appear below the main pot, growing downward
- StatusBar and PotChips have zIndex=2 to render on top of player slots when side pots overlap

## Files Changed

### Modified
- **miko-ui/src/components/StatusBar.ts** — changed potLabel anchor from (0.5, 0.5) to (0.5, 0) for downward text growth; adjusted y position; updated `getPotLabelScenePosition` to return visual center of first line
- **miko-ui/src/scenes/GameScene.ts** — set zIndex=2 on StatusBar and PotChips; adjusted potChips.y to match new pot label position
- **miko-ui/src/managers/GameManager.ts** — removed chip stack y-adjustment code that pushed chips upward per pot line; removed unused `lineCount` variable
