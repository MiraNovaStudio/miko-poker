# Add safety guards to prevent game freezes — 20260322.1833

## Summary
Added multiple safety mechanisms to prevent the game loop from permanently freezing:

1. **Folded/all-in player loop detection**: `advanceGame` was re-calling itself on folded/all-in players, but the engine's `currentPlayerIndex` wasn't advancing, causing an infinite 100ms retry loop. Added a retry counter (`_advanceRetries`) that forces hand completion after `players.length * 2` retries.

2. **Single active player safety**: If only 0-1 active players remain (all others folded), force hand completion immediately rather than relying on the engine to detect it.

3. **AI action error recovery**: If `processAction` throws an error for an AI player, `advanceGame` was never called again, killing the game loop. Now retries after 1 second.

4. **Comprehensive state resets in `onHandStarted`**: Added `_advanceRetries` and `_lastKoCount` to the list of flags reset at each new hand.

5. **Null player guard**: Added warning log when `currentPlayerIndex` points to a null player.
