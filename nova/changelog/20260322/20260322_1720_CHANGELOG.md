# Fix last action label not visible on fold wins — 20260322.1720

## Summary
Fixed an issue where the last player's action label (e.g. "Fold") and card fold animation were not visible before the hand result was shown. The engine fires `hand_complete` synchronously right after `player_action` when a fold leaves only one player remaining. This caused `onHandComplete` to clear all bet labels in the same frame the fold label was set, so the user never saw it.

Fix: defer `onHandComplete` processing by 1200ms for fold wins (hands with no `winningHand`), giving the fold label and card animation time to be visible before the winner is announced.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — added `_foldWinDeferred` flag and 1200ms deferral in `onHandComplete` for fold wins; reset flag on game restart
