# Fix PNG deck cards not appearing — 20260322.1508

## Summary
Fixed a bug where switching to PNG deck mode caused all cards to disappear. The `loadCardPngs()` call was not being awaited, so the deck type changed before textures finished loading, resulting in invisible sprites.

## Files Changed

### Modified
- **miko-ui/src/main.ts** — await `AssetManager.loadCardPngs()` in the PNG deck button click handler
