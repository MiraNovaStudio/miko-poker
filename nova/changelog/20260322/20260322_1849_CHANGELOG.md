# Fix infinite fold-win deferral loop causing game freeze — 20260322.1849

## Summary
Found and fixed the root cause of repeated game freezes on fold wins. The `onHandComplete` fold-win deferral had an infinite recursion bug:

1. First call: `_foldWinDeferred = false` → enters deferral block, sets flag to `true`, defers 1200ms
2. Deferred callback: resets `_foldWinDeferred = false`, then calls `onHandComplete(result)`
3. Second call: `_foldWinDeferred = false` (just reset!) → enters deferral block AGAIN → infinite loop

Every fold win (where all opponents fold and the last player wins) triggered this infinite 1200ms deferral loop that never processed the hand result.

Fix: don't reset `_foldWinDeferred` in the deferred callback. Leave it `true` so the second `onHandComplete` call sees `!true = false`, skips the deferral, and processes the hand normally. The flag is reset in `onHandStarted` for the next hand.
