# Waitlist Feature — 20260325.0033

## Summary
Added a Waitlist button to the game menu and a pre-shuffled player queue system:
1. **Waitlist queue**: At game start, the full 34-player roster is shuffled. First 7 sit at the table, remaining 27 form an ordered waitlist. When a seat opens, the next player in line joins (FIFO) instead of random selection.
2. **Waitlist modal**: Accessible from the game menu (MikoPoker > Waitlist). Shows all waiting players with their avatar and name in queue order.
3. **Refactored replacement system**: All `pickNewPlayer()` calls replaced with `dequeueWaitlistPlayer()` which pulls from the ordered waitlist. Public `getWaitlist()` getter exposes the queue for UI display.

- **miko-ui/src/managers/GameManager.ts** — Added `waitlist` array, `dequeueWaitlistPlayer()`, `getWaitlist()`. Replaced all `pickNewPlayer` calls with waitlist dequeue. Built waitlist from shuffled roster remainder at game start.
- **miko-ui/src/main.ts** — Hoisted `renderAvatarToCanvas()` to outer scope. Wired up waitlist button, modal open/close, and avatar rendering for each waitlist entry.
