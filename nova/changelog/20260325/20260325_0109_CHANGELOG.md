# MiraNova Bounty Feature — 20260325.0109

## Summary
Added a bounty system for the special player MiraNova. When the human player knocks out MiraNova (must be the hand winner), a bounty modal appears with fireworks showing "You knocked out MiraNova! +$10,000 Bounty Added". After clicking Continue, the bounty chips are awarded to the player's stack with the level-up sound, and the game resumes.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `_pendingBounty`, `_bountyChipsFrom/To` fields, `onBounty` callback, `onBountyDismissed()` method. MiraNova elimination detection in `checkForEliminatedPlayers`. Bounty processing in `scheduleNextHand` pauses game flow until modal is dismissed.
- **miko-ui/src/scenes/GameScene.ts** — Wired `onBounty` callback to open bounty modal with fireworks. Added `startBountyFireworks()`/`stopBountyFireworks()` methods. Continue button dismisses modal and calls `onBountyDismissed()`.
- **miko-ui/index.html** — Added bounty modal HTML with fireworks canvas, title, message, amount, and continue button
- **miko-ui/src/styles.css** — Added bounty modal styles with gold border, green amount text, glow effects
