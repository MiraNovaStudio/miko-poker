# Strip private deploy targets — 20261124.0610

## Summary
Removed the hardcoded S3 bucket and CloudFront distribution id from the publish script so the repo can be public. `deploy.sh` now reads `deploy.env` or the environment, and asks at a terminal when a required value is missing. The nginx sample uses `poker.example.com` instead of the studio dev host.

- **build.sh** — point at `deploy.sh` instead of a private S3 push
