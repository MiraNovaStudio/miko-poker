# Make a missing install obvious in build.sh — 20261124.0615

## Summary
`./build.sh` failed on Windows with `tsc is not recognized` because `node_modules` was absent. The script now exits with an `npm install` instruction in that case. `npm install` also synced the lockfile package version from 0.5.4 to 0.6.4.

## Files Changed

### Modified
- **build.sh** — stop early when the local TypeScript binary is missing
- **package-lock.json** — root, engine, and UI versions set to 0.6.4
