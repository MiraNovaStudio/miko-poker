# Flash action name in chip overlay on call/raise/bet — 20260321.1206

## Summary
When a player calls, raises, or bets, the action name (Call, Raise, Bet, All In) now briefly flashes in their chip stack overlay for 1 second before returning to the chip amount. This makes it easier to tell what action was taken, since the bet label only shows the amount for these actions (unlike Check/Fold which display as text).

## Files Changed

### Modified
- **miko-ui/src/components/PlayerSlot.ts** — Added `flashAction()` method that temporarily replaces the chip label text with an action name, then restores after a timeout
- **miko-ui/src/managers/GameManager.ts** — Called `flashAction()` in `onPlayerAction()` for call, raise, bet, and allin actions
