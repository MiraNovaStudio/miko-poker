# Add pot type subtitles to WINNER labels — 20260321.2243

## Summary
When side pots are in play, the WINNER label now shows a subtitle indicating which pot was won. Side pot winners see "WINNER!" with "Side Pot" below it, and main pot winners see "WINNER!" with "Main Pot" below it. Single-pot hands still show just "WINNER!" with no subtitle.

## Files Changed

### Modified
- **miko-ui/src/components/PlayerSlot.ts** — Added optional `subtitle` parameter to `showWinnerLabel()` that renders a smaller text line below the main WINNER label; changed `winnerLabel` field type from `Text` to `Container` to support the two-line layout; updated `showButtonLabel()` and `showKnockedOutLabel()` for type compatibility
- **miko-ui/src/managers/GameManager.ts** — Added optional `subtitle` parameter to `highlightWinnerNames()`; passes "Side Pot" or "Main Pot" as subtitle during multi-pot awards
