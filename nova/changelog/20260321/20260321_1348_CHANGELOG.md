# Fix eliminated players not being replaced — 20260321.1348

## Summary
Two fixes:

1. **Replacements not queued**: When `checkForEliminatedPlayers(true)` was called with `deferGameOver=true` (during showdown), it returned early BEFORE the replacement queueing code. Eliminated AI players were never added to `deferredReplacements`, so no new players ever joined. Moved the `deferGameOver` return to AFTER the replacement loop.

2. **Replacement delay too long**: `handsRemaining` was `2 + Math.floor(Math.random() * 3)` = 2-4 hands. Changed to `1 + Math.floor(Math.random() * 3)` = 1-3 hands as intended.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Moved replacement queueing before the `deferGameOver` early return; fixed `handsRemaining` range from 2-4 to 1-3
