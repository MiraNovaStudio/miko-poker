# Add debugSidePots() for testing side pot scenarios — 20260321.0948

## Summary
Added a new debug command `window.debugSidePots()` to set up a controlled 3-player side pot scenario. After the current hand finishes, the table is reduced to 3 players with different chip stacks (Player=500, ai1=800, ai2=200). Both AI players are overridden to always call/check (never fold or raise), making it easy to reproduce and debug side pot behavior.

### Modified
