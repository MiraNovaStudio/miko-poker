# Fix eliminated player seat refill timing — 20260321.2216

## Summary
Fixed a bug where eliminated player seats could be refilled immediately on the next hand. The `handsRemaining` counter was set to 1-3 but decremented before the check, so a value of 1 resulted in instant replacement (0 hands with empty seat). Changed the range from 1-3 to 2-4 so the effective wait is 1-3 hands with the seat empty before a new player joins.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Changed deferred replacement `handsRemaining` from `1 + Math.floor(Math.random() * 3)` to `2 + Math.floor(Math.random() * 3)` to guarantee at least 1 hand with an empty seat
