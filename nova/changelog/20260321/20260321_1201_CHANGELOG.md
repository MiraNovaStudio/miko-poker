# Fix preaction showing Fold instead of Check/Fold in BB — 20260321.1201

## Summary
When the player was in the BB and a short-stacked AI went all-in for less than the BB amount, the preaction button incorrectly showed "Fold" instead of "Check/Fold". The `canCheck` logic was using `gameState.callAmount` which is relative to the current AI player, not the human. Now it compares the human's bet against the highest bet at the table to correctly determine if the human can check.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Replaced `gameState.callAmount === 0` with `humanPlayer.bet >= highBet` for preaction check/fold determination; also fixed the raise-detection branch to use the same `highBet` comparison
