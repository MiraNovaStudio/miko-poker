# Fix preflop action order when players are eliminated — 20260321.0837

## Summary
Fixed a bug where the big blind was asked to act first preflop instead of UTG. The `getFirstToActPreflop()` method calculated UTG as `dealerIndex + 3`, which assumes no eliminated players between the dealer and BB. When eliminated players shifted the SB/BB positions forward, `+3` could land on the BB itself. Now the method finds the actual BB position (skipping eliminated players, matching `postBlinds()` logic), then sets UTG as the next active player after the BB.
