# Loading Screen — 20260321.2200

## Summary
Added a loading screen with a CSS spinner and asset progress bar. The spinner appears instantly in the HTML before any JavaScript loads, addressing slow load times on t2.micro instances. Once JS initializes, the spinner transitions to a progress bar that shows real-time asset download progress via PixiJS Assets API. The overlay fades out when loading completes.

## Files Changed

### Modified
- **miko-ui/index.html** — Added `#loading-overlay` with inline CSS spinner, progress bar, and status text (renders before JS bundle)
- **miko-ui/src/main.ts** — Switches spinner to progress bar during asset loading, updates percentage, fades out overlay when done
- **miko-ui/src/managers/AssetManager.ts** — Added optional `onProgress` callback parameter to `load()`, passed to `Assets.load()`
