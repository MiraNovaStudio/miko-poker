# Fix favicon 404 and winner label crash — 20260321.1137

## Summary
Fixed two console errors:

1. **favicon.ico 404**: Added `<link rel="icon">` tag pointing to `assets/favicon.png` so the browser doesn't request the default `favicon.ico`.

2. **PlayerSlot crash** (`Cannot read properties of null`): The winner/button/KO label animation callbacks could crash when `hideWinnerLabel()` destroyed the label while a `requestAnimationFrame` callback was still pending. Added `label.destroyed` guard checks to all three animation loops.

### Modified
- **miko-ui/index.html** — Added favicon link tag
- **miko-ui/src/components/PlayerSlot.ts** — Added `destroyed` checks in `showWinnerLabel`, `showButtonLabel`, and `showKnockedOutLabel` animation callbacks
