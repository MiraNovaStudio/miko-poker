# Always show separate pot award animations for side pots — 20260321.1026

## Summary
When the same player won both the side pot and main pot, the engine was filtering out `potResults` (via `hasDistinctWinners`) and the UI showed a single combined award animation instead of separate animations for each pot. Now `potResults` is always included when there are multiple pot layers, so the UI correctly animates each pot award individually (e.g. "Side Pot: $600" then "Main Pot: $600").

## Files Changed

### Modified
- **engine/src/game-engine.ts** — Removed `hasDistinctWinners` filter; `potResults` is now included whenever `potResults.length > 1`. Removed the unused `hasDistinctWinners` method.
