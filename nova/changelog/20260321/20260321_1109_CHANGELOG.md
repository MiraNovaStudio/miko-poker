# Add Sit Out checkbox — 20260321.1109

## Summary
Added a "Sit Out" checkbox above the History button. When checked, the player automatically folds on every action except when in the big blind with no bet to face — then the player checks. This allows the game to continue playing in the background while the player sits out. The player can still win the pot in the BB if no further betting occurs and they have the best hand at showdown.

## Files Changed

### Modified
- **miko-ui/src/components/HandHistory.ts** — Added sit-out checkbox element, positioned above History button, with `sitOut` getter and `onSitOutChanged` callback. Updated `enable()`, `updatePosition()`, and `destroy()` to handle the new element.
- **miko-ui/src/managers/GameManager.ts** — Added sit-out check in `advanceGame()` before preaction handling: auto-checks when `canCheck` is true (BB with no raise), auto-folds otherwise.
