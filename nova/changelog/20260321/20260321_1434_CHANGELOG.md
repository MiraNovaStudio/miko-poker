# Improve Debian package build — 20260321.1434

## Summary
Fixed and improved the existing `deploy/build-dpkg.sh` Debian package builder:

1. **Fixed architecture**: Filename changed from `_amd64.deb` to `_all.deb` to match `Architecture: all` in the control file
2. **Added conffiles**: Declared nginx config and systemd service as conffiles so dpkg won't overwrite admin edits on upgrade
3. **Bundled serve**: The `serve` static file server is now installed into the package's `node_modules/` during build, eliminating the need for internet access on the target machine
4. **Removed npm dependency**: No longer requires `npm` at runtime (only `nodejs`)
5. **Updated service file**: Uses bundled `serve` via `node_modules/.bin/serve` instead of `npx`
6. **Updated SETUP.md**: Added "Install via Debian Package" section

## Files Changed

### Modified
- **deploy/build-dpkg.sh** — Fixed filename, added conffiles, bundled serve, removed `npm install -g serve` from postinst
- **deploy/mikopoker.service** — Updated ExecStart to use bundled serve
- **SETUP.md** — Added deb package installation instructions
