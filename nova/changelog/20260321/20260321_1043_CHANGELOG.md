# Reuse existing pot labels during award ceremony — 20260321.1043

## Summary
The award ceremony was rebuilding pot labels using a different format ("Main Pot" vs "Main") and slightly different positioning. Now the ceremony reuses the existing on-screen pot label text (which uses "Main: $X" / "Side: $Y" format) and simply removes lines from the bottom as each pot is awarded, keeping the display consistent throughout.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Award ceremony now reads the current pot label text via `getPotText()`, splits into lines, and removes the last line after each award instead of rebuilding from `potResult.potLabel`
