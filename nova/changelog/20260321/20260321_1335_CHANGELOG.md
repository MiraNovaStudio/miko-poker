# Award uncontested side pots immediately — 20260321.1335

## Summary
Implemented the standard poker rule: side pots with only one eligible player are awarded immediately when the betting round ends, not held until showdown. This prevents showing side pots at showdown between players who should have already received those chips.

The engine now calls `pot.awardUncontestedLayers()` after each `collectBets()` in `endBettingRound()`. Layers with a single eligible player (e.g., because everyone else in that pot folded) are awarded immediately and a `side_pot_awarded` event is emitted. At showdown, `awardPots()` skips layers whose sole eligible player was already pre-awarded.

The UI handles the new event with an animation showing the side pot chips flying to the winner, and updates the pot label and chip display accordingly.
