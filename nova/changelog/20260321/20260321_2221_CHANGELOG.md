# Fix side pot award animation and history logging — 20260321.2221

## Summary
Fixed the side pot award animation so pot labels stay visible during the fly animation instead of collapsing immediately. Previously, each pot label line was removed as soon as the award started, so you'd see the label disappear before chips even landed. Now the awarded line is removed only after the 1400ms fly animation completes, keeping remaining pot labels (e.g. Main pot) visible while the side pot chips fly to the winner. Also changed hand history to log each pot award as a separate entry instead of one combined line.
