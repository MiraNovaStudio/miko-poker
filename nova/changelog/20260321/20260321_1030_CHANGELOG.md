# Expand debugSidePots to support 1, 2, or 3 side pot scenarios — 20260321.1030

## Summary
Updated `debugSidePots()` to accept a parameter (1, 2, or 3) controlling the number of side pots. Each scenario adds more players with progressively smaller stacks, all with AI overridden to always call.

- **debugSidePots(1)**: 3 players — You=500, ai1=800, ai2=200
- **debugSidePots(2)**: 4 players — You=500, ai1=800, ai2=200, ai3=100
- **debugSidePots(3)**: 5 players — You=500, ai1=800, ai2=200, ai3=100, ai4=50

Invalid parameters log an error message.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Refactored `debugSidePots()` and `applyDebugSidePots()` to support parameterized scenarios
- **miko-ui/src/main.ts** — Updated window binding to pass parameter
