# Fix history button persisting on start screen — 20260321.0724

## Summary
When quitting back to the start screen after running out of chips, the History button and panel remained visible because HandHistory's DOM elements were never cleaned up. Added a `destroy()` method to GameManager and called it from GameScene's destroy to properly remove the History button and panel when leaving the game.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `destroy()` method that calls `handHistory.destroy()`
- **miko-ui/src/scenes/GameScene.ts** — Added `this.gameManager?.destroy()` call in `destroy()`
