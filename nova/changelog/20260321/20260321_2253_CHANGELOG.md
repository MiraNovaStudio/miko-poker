# Fix false MikoPoker victory in debugSidePots — 20260321.2253

## Summary
When `debugSidePots()` eliminates players not needed for the scenario, it was leaving MikoPoker's display name in the eliminated set. When the last debug AI busted, the "last one standing" victory check found MikoPoker in the eliminated players and falsely declared "You knocked out MikoPoker!" even though MikoPoker was never actually in the hand. Fixed by clearing MikoPoker's display name from debug-eliminated players so the victory check won't match it.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — In `applyDebugSidePots()`, rename MikoPoker's display name to `[debug-removed]` for players eliminated by the debug setup to prevent false victory triggers
