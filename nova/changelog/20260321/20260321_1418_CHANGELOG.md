# Add Keep Playing button after victory — 20260321.1418

## Summary
After knocking out MikoPoker (or eliminating all opponents), the victory modal now shows a "Keep Playing" button alongside "New Game". Clicking "Keep Playing" dismisses the victory screen, fills empty seats with new opponents from the roster, and continues the game without resetting chips or hand history.

## Files Changed

### Modified
- **miko-ui/index.html** — Added `keep-playing-btn` button in the game-over modal
- **miko-ui/src/scenes/GameScene.ts** — Show "Keep Playing" on victory; wire click handler to `gameManager.keepPlaying()`
- **miko-ui/src/managers/GameManager.ts** — Added `keepPlaying()` method that resets victory state, queues replacements for all eliminated AI seats, applies them with slide-in animation, then starts a new hand
