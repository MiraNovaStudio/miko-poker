# Realistic card dealing order — 20260321.1358

## Summary
Changed the engine's card dealing to follow standard poker dealing procedure:

1. **Deal order**: Cards are dealt starting with the player to the left of the dealer button, going clockwise, ending with the dealer — one card at a time per round (two rounds total).

Previously, cards were dealt in player array order with both cards given at once via `dealMultiple(2)`.

Burns before flop, turn, and river were already correctly implemented in both `advanceStreet()` and `forceHandComplete()`.

## Files Changed

### Modified
- **engine/src/game-engine.ts** — Rewrote `startNewHand()` dealing logic to build a clockwise deal order from `dealerIndex+1`, deal one card per player per round for 2 rounds, then emit `cards_dealt` events
