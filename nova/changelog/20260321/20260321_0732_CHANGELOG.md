# Add Show Avatars setting — 20260321.0732

## Summary
Added a new "Show Avatars" toggle in the Settings panel that lets players show or hide all player avatars. Defaults to on. The toggle takes effect immediately — turning it off clears all avatar sprites, turning it back on restores them.

## Files Changed

### Modified
- **miko-ui/src/managers/SettingsManager.ts** — Added `showAvatars` boolean setting with localStorage persistence (`miko_showAvatars` key, default: true)
- **miko-ui/index.html** — Added "Show Avatars" On/Off toggle row in the settings panel
- **miko-ui/src/main.ts** — Added DOM references, event listeners, and initial sync for the avatars toggle buttons
- **miko-ui/src/managers/GameManager.ts** — Updated `applyAvatar()` to check `showAvatars` setting (clears avatar if off); updated onChange handler to refresh all player avatars when settings change
