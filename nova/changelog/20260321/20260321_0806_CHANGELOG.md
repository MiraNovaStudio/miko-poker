# Fix side pot labels and award count during all-in runout — 20260321.0806

## Summary
Fixed two issues with multi-player all-in scenarios:

1. **Side pot labels collapsing**: When all players were all-in and the board was being run out, the side pot breakdown (Main/Side labels) was replaced with a single "Pot: $X" label. Now the full side pot breakdown is snapshotted before `forceHandComplete()` resets the engine state, so the labels persist throughout the runout.

2. **Excess awards at showdown**: The single-pot award path was using `perPlayerWinnings` (chip deltas) to determine who to animate awards for, which could include players who received uncalled bet returns but weren't actual hand winners. Now only `result.winners` are considered for award display and animation.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts**
  - `advanceGame()`: Snapshot side pot breakdown before `forceHandComplete()` and display multi-line pot labels during runout
  - `onHandComplete()`: Single-pot path now filters award display/animation to only actual hand winners from `result.winners`
