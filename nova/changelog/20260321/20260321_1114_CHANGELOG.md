# Merge spurious pot layers with same eligible players — 20260321.1114

## Summary
Folded players' blind contributions were creating extra pot layers with the same eligible players, causing multiple award animations for what is effectively a single pot. For example, a folded SB with $5 and two all-in players at $500 each would create 2 layers both eligible to [A, B] — resulting in 2 separate award ceremonies instead of 1.

Now `computeLayers()` merges adjacent layers that have identical eligible player sets. Genuine side pots (where different players are eligible at different levels) remain separate.
