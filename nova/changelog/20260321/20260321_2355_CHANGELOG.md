# Fix missing cards when tab is backgrounded — 20260321.2355

## Summary
When the browser tab was in the background during a card deal, `requestAnimationFrame` callbacks were paused by the browser, leaving cards invisible (alpha=0, scale=0.3) while the game continued advancing via `setTimeout`. Players would return to see some seats with no cards but the hand already in progress.

Fixed by checking `document.hidden` before starting RAF-based animations. If the tab is hidden, cards are placed at their final position immediately (no animation) so they're always visible when the user returns.

## Files Changed

### Modified
- **miko-ui/src/components/PlayerSlot.ts** — Skip deal animation and place cards immediately when `document.hidden` is true
- **miko-ui/src/components/CommunityCards.ts** — Same fix for community card deal animation
