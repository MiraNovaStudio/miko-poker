# debugHandLog — 20260323.1854

## Summary
Added `debugHandLog(handNum)` console command for post-hand debugging. Shows a concise per-hand summary: actions by street, showdown hands, pot structure (main + side), awards, and starting/ending stacks for all involved players. Accepts flexible input — `debugHandLog(5)`, `debugHandLog("5")`, and `debugHandLog("005")` all show hand #005.
