# Game Menu — 20260323.2059

## Summary
Replaced the About modal with a game menu. Clicking the "MikoPoker" title or pressing Escape now pauses the game and opens a menu with Resume, New Game, and Quit Game buttons. Pressing Escape or P while the menu is open closes it and resumes. The `pause()` and `unpause()` methods on GameManager are now public.

## Files Changed

### Modified
- **miko-ui/index.html** — Replaced `#about-modal` with `#game-menu-modal` containing Resume, New Game, and Quit Game buttons plus version/copyright text.
- **miko-ui/src/styles.css** — Replaced about modal CSS with game menu styles (z-index 8500 to sit above pause overlay, stacked button layout).
- **miko-ui/src/main.ts** — Replaced about modal handlers with `openGameMenu()`/`closeGameMenu()` functions. MikoPoker title click and Escape key both toggle the menu. P key closes menu if open. Menu buttons: Resume unpauses, New Game restarts, Quit returns to start screen.
- **miko-ui/src/managers/GameManager.ts** — Made `pause()` and `unpause()` public (were private). Added early-return guards for idempotent calls.
