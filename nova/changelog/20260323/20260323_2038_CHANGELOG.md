# Pot Eligibility Dots — 20260323.2038

## Summary
Added color-coded dot indicators to show which players are eligible for each pot. Each pot line (Main, Side 1, Side 2, etc.) gets a colored dot, and matching dots appear next to each eligible player's slot. Green = Main pot, blue = Side 1, orange = Side 2, etc. (8 colors total for up to 7 side pots). Dots appear on the right side of player slots except seat 6 (ai6) which shows dots on the left. Dots are always shown — even for a single main pot — and clear at hand start and showdown.

Also fixed debugHandLog action amounts: raise/bet actions now show actual incremental chips put in (computed from engine state) instead of the raw raise-to target. Players who go all-in via a raise are now correctly labeled as "allin" in the log.

## Files Changed

### Modified
- **miko-ui/src/utils/constants.ts** — Added `POT_DOT_COLORS` (8-color palette) and `POT_DOT_LEFT_SEATS` constants.
- **miko-ui/src/components/PlayerSlot.ts** — Added `setPotDots(colors)` and `clearPotDots()` methods with a dots container positioned right (or left for seat 6) of the chip overlay. Dots cleared in `resetForNewHand()`.
- **miko-ui/src/components/StatusBar.ts** — Refactored pot display to support `setPotWithDots(lines)` which renders colored dot + text per pot line. Backward-compatible `setPot(text)` still works for simple text.
- **miko-ui/src/managers/GameManager.ts** — `updatePotLabel()` now tracks eligible player IDs per pot layer and calls `setPotWithDots` + `updatePlayerPotDots`. All-in runout paths also show dots. Added `updatePlayerPotDots`, `clearAllPotDots`, and `showMainPotDot` helpers.
- **miko-ui/src/utils/HandLog.ts** — `recordAction` now accepts `streetBet` and `isAllIn` from engine state to compute accurate incremental amounts. Tracks per-player street bets internally.
