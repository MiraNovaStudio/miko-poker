# Fix Two Pair kicker evaluation & show board in hand log — 20260327.2040

## Summary
Fixed a bug where the Two Pair kicker was incorrectly selected when a player had 3+ pairs across 7 cards. The `groups.find()` picked the first non-top-pair group by count order rather than the highest-value remaining card, causing lower-ranked kickers to be chosen over higher ones (e.g., a 3 chosen over an Ace). Also added a full board display line to the hand log so turn/river cards are visible even when no betting occurred on those streets.

## Files Changed

### Modified
- **engine/src/hand-evaluator.ts** — Fixed Two Pair kicker selection to pick the highest remaining card value instead of the first group by count order
- **engine/tests/basic.test.ts** — Added 2 tests: 3-pair kicker selection and kicker-based hand comparison for the exact scenario that triggered the bug
- **miko-ui/src/utils/HandLog.ts** — Added "Board [...]" section showing all community cards before the Showdown section
