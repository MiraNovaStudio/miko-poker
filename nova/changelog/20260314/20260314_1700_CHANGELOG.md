# Fix Check/Fold pre-action button visibility logic — 20260314.1700

## Summary
Refined the Check/Fold pre-action button so it only appears when a future automatic action is meaningful. Previously the button was shown on every AI turn regardless of whether the human had already acted. Now it follows these rules:

- No bet yet → show "Check/Fold"
- Bet exists and player hasn't acted → show "Fold"
- Player calls/checks/bets/folds → hide the button
- A raise occurs after the player called → show "Fold" (new decision needed)
- New hand or street change → reset state

Added `humanActedThisStreet` flag to track whether the human has acted in the current betting round. The flag is set on all action paths (manual buttons, pre-action auto-execute) and reset on hand start, street change, and game restart.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `humanActedThisStreet` tracking flag; updated AI turn preaction logic to hide button after human acts and re-show only on raise; set flag in `onCheckOrCall()`, `onBetOrRaise()`, `onFold()`, and preaction auto-execute; reset on hand start, street change, and restart
