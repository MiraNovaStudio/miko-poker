# Fix stale raise amount bug — 20260314.1752

## Summary
Fixed a bug where clicking Raise with no amount would produce a massively inflated raise (e.g., $477 instead of $20). Root cause: `BettingRound.reset()` was not called in `startNewHand()`, so `lastRaiseAmount` from the previous hand's last street leaked into the next hand. This caused `minRaiseAmount` (and the engine's raise floor) to use the stale value. Also simplified the UI's raise/bet logic now that the engine always has correct state.

## Files Changed

### Modified
- **engine/src/game-engine.ts** — added `this.bettingRound.reset()` in `startNewHand()` to clear stale raise state
- **miko-ui/src/managers/GameManager.ts** — simplified `onBetOrRaise()` and min-amount calculation, removed workaround for stale preflop raise data

### Added
- **engine/tests/raise.test.ts** — 7 unit tests verifying correct min-raise amounts across hands, no stale state leakage, raise enforcement
