# Extract CSS to separate file, improve obfuscation — 20260314.2002

## Summary
Moved all inline CSS from index.html `<style>` tag into a separate `src/styles.css` file. Vite processes it into a hashed CSS file in the build output. Also improved obfuscation: added `sourceMap: false` to obfuscator options, bumped `stringArrayThreshold` from 0.5 to 0.75 for better string coverage, and added `apply: 'build'` to ensure plugin only runs on production builds.

## Files Changed

### Added
- **miko-ui/src/styles.css** — all CSS extracted from index.html

### Modified
- **miko-ui/index.html** — replaced `<style>` block with `<link rel="stylesheet" href="/src/styles.css">`
- **miko-ui/vite.config.ts** — added `apply: 'build'`, `sourceMap: false`, bumped `stringArrayThreshold` to 0.75
