# Add fold confirmation after bet interaction — 20260314.2008

## Summary
If the player interacts with the bet slider or pot-fraction buttons (1/4, 1/2, 3/4, Pot, All In) and then clicks Fold, the button changes to "Sure?" requiring a second click to confirm. This prevents accidental folds when the player clearly intended to bet. Normal folds (no slider/button interaction) work immediately with a single click. State resets each turn when the action bar appears, and resets to "Fold" if the player goes back to adjusting the slider.

## Files Changed

### Modified
- **miko-ui/src/components/ActionBar.ts** — added `_betInteracted` and `_foldConfirming` flags; fold button now calls `handleFoldClick()` which shows "Sure?" on first click if bet controls were used; `resetFoldConfirm()` restores "Fold" label; slider and pot-fraction button handlers set `_betInteracted`; flags reset in `show()`
