# Add animated pot chip stack with fly-to-winner animation — 20260314.1822

## Summary
Added a visual poker chip stack that builds above the pot label as the pot grows. Chips use denomination-based colors (white $1, red $5, blue $10, green $25, black $100, purple $500) rendered as 3D-styled ellipse discs with edge shading and accent stripes. On showdown, the chip graphics fly alongside the pot label text to the winner's chip stack with staggered ease-in-out cubic animation, then disappear on arrival as the chip count spins up.

## Files Changed

### Added
- **miko-ui/src/components/PotChips.ts** — new component: renders stacked poker chip discs via Graphics primitives, decomposes pot amounts into denominations, creates flying chip clones for win animation

### Modified
- **miko-ui/src/scenes/GameScene.ts** — creates PotChips instance positioned above pot label, passes it to GameManager
- **miko-ui/src/managers/GameManager.ts** — updates chip stack on every pot change via `potChips.update()`, creates flying chip animations in `animatePotToWinners()` that fly alongside the pot text to winners, clears stack on hand end
