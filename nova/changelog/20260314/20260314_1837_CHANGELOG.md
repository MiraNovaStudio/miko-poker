# Add card back selection setting — 20260314.1837

## Summary
Added 8 card back designs players can choose from in settings. Each design has a unique color scheme and center pattern (diamond, cross, stripes, or oval). Selection is persisted to localStorage. The settings panel shows a live preview, and clicking "Choose" opens a picker grid similar to the avatar selector.

Designs: Classic Blue (default), Royal Red, Emerald, Midnight, Burgundy, Charcoal, Ocean, Purple Haze.

## Files Changed

### Modified
- **miko-ui/src/components/Card.ts** — added `CardBackDesign` interface, `CARD_BACK_DESIGNS` array (8 designs), and updated `drawUnicodeBack()` to render the selected design's color, border, and pattern style
- **miko-ui/src/managers/SettingsManager.ts** — added `cardBack` property with localStorage persistence (default: 'classic-blue')
- **miko-ui/src/main.ts** — wired card back picker: draws designs to canvas previews, handles selection, updates preview on load
- **miko-ui/index.html** — added Card Back setting row with preview + Choose button, card back picker modal with 4-column grid, CSS for picker
