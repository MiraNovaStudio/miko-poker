# Gender-Aware Avatar Generation — 20260314.1741

## Summary
Added gender field to player roster and avatar generator so female players never get beards and have higher earring probability, while male players never get earrings and can have beards. This eliminates the need for manual avatar swaps to fix gender mismatches.

## Files Changed

### Modified
- **miko-ui/src/data/player-roster.ts** — added `Gender` type and `gender` field to `RosterEntry`; tagged all 34 roster entries (9 female, 25 male)
- **miko-ui/src/utils/createAvatar.ts** — `createAvatar()` now accepts optional `gender` param; females skip beard, 40% earring chance; males skip earrings, 30% beard chance
- **miko-ui/src/managers/GameManager.ts** — `getAvatarTexture()` and `applyAvatar()` pass gender through to avatar generator; updated all 3 call sites
- **miko-ui/src/tests/player-roster.test.ts** — updated test to validate gender field on every roster entry
