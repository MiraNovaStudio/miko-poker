# Fix replacement players having no cards dealt — 20260314.2036

## Summary
Fixed a bug where replacement players (those who join after another is eliminated) would play without visible cards. Root cause: when a player was replaced, `playerIdBySeat` and `seatByPlayerId` were never updated with the new engine ID. This caused `getSlotForPlayer()` to return null for the new player, and `onCardsDealt()` would retry infinitely without ever finding a slot. Fixed by updating both seat mappings in both replacement paths (instant and animated). Also added a retry limit (20 attempts) to `onCardsDealt()` to prevent infinite loops.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — update `playerIdBySeat` and `seatByPlayerId` in both `applyPendingReplacements()` and `applyPendingReplacementsAnimated()`; added retry limit with console warning in `onCardsDealt()`
