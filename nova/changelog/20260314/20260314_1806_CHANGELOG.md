# Add Avatar Selection Setting — 20260314.1806

## Summary
Added avatar selection to settings, allowing the player to choose from 6 preset avatars (3 male, 3 female) with varying skin tones. The current avatar is shown as a preview in the settings panel, and clicking "Choose" opens a popup grid of all options. Selection is persisted to localStorage.

## Files Changed

### Modified
- **miko-ui/index.html** — added Avatar setting row with preview canvas and Choose button; added avatar picker modal with grid; added CSS for avatar picker
- **miko-ui/src/main.ts** — wired avatar picker: renders PixiJS avatars to HTML canvases, handles selection, updates preview, persists choice
- **miko-ui/src/managers/SettingsManager.ts** — added `avatarPreset` property with localStorage persistence (default: 'male1')
- **miko-ui/src/managers/GameManager.ts** — human player now uses selected avatar preset instead of name-based generation
- **miko-ui/src/utils/createAvatar.ts** — added `AVATAR_PRESETS` array (6 presets) and `AvatarPreset` interface export
