# Add JavaScript obfuscation to production build — 20260314.1903

## Summary
Added `vite-plugin-javascript-obfuscator` to the build pipeline. Production builds (`npm run build`) now obfuscate all JS output with control flow flattening, dead code injection, string array encoding (base64), hex identifier names, and object key transformation. Dev mode (`npm run dev`) and tests are unaffected. Sourcemaps are disabled in production to prevent defeating the obfuscation.

## Files Changed

### Modified
- **miko-ui/vite.config.ts** — converted to function config; added obfuscator plugin for production mode only; disabled sourcemaps in build
- **miko-ui/package.json** — added `javascript-obfuscator` and `vite-plugin-javascript-obfuscator` devDependencies
