# Refine About modal: dynamic version, OK button, darker overlay — 20260313.0954

## Summary
Updated the About modal based on feedback: panel background now matches the app background (#1a1a2e), backdrop overlay is darker (rgba 0,0,0,0.75), clicking outside no longer dismisses — only the new OK button closes it. Version is now pulled dynamically from package.json via Vite's `define` config instead of being hardcoded.
