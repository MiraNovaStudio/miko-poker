# Add About modal on MikoPoker title click — 20260313.0951

## Summary
Added an About modal that appears when clicking the "MikoPoker" page title during gameplay. The modal displays "Miko Poker (Demo)", the current version (0.1.0), and a copyright line for MiraNova Studios. The background uses the app's dark color with opacity overlay, matching the existing modal styling. Clicking the backdrop dismisses the modal.
