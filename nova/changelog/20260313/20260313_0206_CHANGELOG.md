# Fix raise default amount and show min raise in input placeholder — 20260313.0206

## Summary
Two fixes for the raise action:

1. **BB preflop raise bug**: When the big blind raises preflop, `canBet` is true but the engine rejects 'bet' because `currentBet > 0` (the BB). Changed to always send 'raise' preflop, matching the button label.

2. **Raise amount UX**: The bet input had no placeholder, so clicking Raise with an empty field silently used the min raise amount — which can be very large after a previous raise. The input now shows the min raise/bet as placeholder text (e.g. "$390") so the user knows what amount will be committed.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Fixed `onBetOrRaise()` to send 'raise' (not 'bet') preflop; added `setMinBet()` call when showing action bar to display min amount in placeholder
- **miko-ui/src/components/ActionBar.ts** — Added `setMinBet(amount)` method to update the input placeholder
