# Fix stale min raise amount in bet input placeholder — 20260313.0257

## Summary
The bet input placeholder was showing inflated min raise amounts (e.g. $415 instead of $20) because the engine's `lastRaiseAmount` from the previous hand persists into the next hand (BettingRound.reset() is not called in startNewHand()). Fixed by computing a correct floor in the UI: for preflop BB option use `2 * bigBlind`, for normal raises use `callAmount + playerBet + bigBlind` as a cap.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Fixed min raise placeholder and default raise amount in `advanceGame()` and `onBetOrRaise()` to avoid stale engine `minRaiseAmount`; preflop BB option now shows `2 * BB` as min raise
