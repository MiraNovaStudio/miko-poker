# Fix side pot display: only show when all-in, stack vertically — 20260313.0358

## Summary
Fixed two issues with side pot display:
1. Side pots were showing whenever players had different totalBet amounts (e.g. different blind sizes), but they should only appear when at least one player is all-in — that's when a player can't match further bets and a separate pot must be created.
2. Side pot labels (SP1, SP2) now stack vertically below the main pot label instead of appearing inline horizontally.

The `computeSidePots()` method now checks `players.some(p => p.allIn)` first, and only splits at contribution levels where an all-in player caps out.

### Modified
- **miko-ui/src/managers/GameManager.ts** — `computeSidePots()`: added all-in gate and split only at all-in cap levels; `updatePotLabel()`: changed SP labels to use `\n` for vertical stacking
