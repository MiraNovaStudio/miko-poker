# Fix game freeze on all-in + reposition bet slider — 20260313.0336

## Summary
Fixed a game freeze that occurred when the human player was all-in and opponents folded down to one remaining AI. The `onPlayerAction` handler was setting `allInRunout = true` when `canActPlayers <= 1`, but it doesn't call `forceHandComplete` (only `advanceGame` does that). This caused `advanceGame` to see `allInRunout` already set and skip calling `forceHandComplete`, leaving the hand stuck forever. Fixed by restricting `onPlayerAction`'s auto-run detection to `canActPlayers === 0` only — matching the engine's own check.

Also redesigned the bet slider panel layout: buttons are now on the LEFT (All In, Pot, 3/4, 1/2, 1/4 top-to-bottom), slider on the RIGHT, positioned beneath seat 6 (right side of table) so all elements are visible on screen.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Changed `onPlayerAction` auto-run check from `canAct.length <= 1` back to `canAct.length === 0` to prevent freeze
- **miko-ui/src/components/ActionBar.ts** — Redesigned slider panel: horizontal flex with buttons column left + slider column right; repositioned beneath seat 6 using design-space coordinates
