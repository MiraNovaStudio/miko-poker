# Fix fold-click to view cards when animations are off — 20260313.0158

## Summary
Fixed the click-on-stack-box to view folded cards not working. When card animations are off, the fold path called `hideCards()` which only toggled visibility without setting up the fold-click handler. Now `hideCards()` sets `_folded = true` and calls `setupFoldHover()`, matching the behavior of the animated `foldCardsTo()` path. Also cleaned up a stale `betLabelBg` reference in `clearBet()`.
