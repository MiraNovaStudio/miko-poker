# New Game modal and double-deal fix — 20260313.0118

## Summary
Replaced the PixiJS New Game button with a centered HTML modal dialog. Added a generation counter to cancel stale setTimeout callbacks on restart, preventing the double-deal bug where a new hand would start mid-hand. Screen is fully cleared before restarting.

## Files Changed

### Modified
- **miko-ui/index.html** — Added #gameover-modal with centered panel, message, and New Game button; styled to match settings modal
- **miko-ui/src/scenes/GameScene.ts** — Removed PixiJS createNewGameButton; wired onGameOver to HTML modal; New Game click calls restart()
- **miko-ui/src/managers/GameManager.ts** — Added `generation` counter incremented on restart; added `delayed()` helper that checks generation before executing; replaced all game-flow `setTimeout` calls with `delayed()`; `onGameOver` now accepts optional message string; `restart()` resets all state including allInRunout/deferredReplacements and hides all slots before reinitializing
