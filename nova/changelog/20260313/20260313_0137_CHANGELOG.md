# Fix eliminated players still participating in hands — 20260313.0137

## Summary
Fixed a bug where eliminated players (0 chips) were still treated as "in the hand" — their cards were compared at showdown, and they blocked fold-wins (forcing the player to act against an eliminated opponent). Root cause: `resetForNewHand()` set `isActive = false` but left `folded = false`, so all fold-win checks and showdown logic (which filter by `!p.folded`) still included them.

## Files Changed

### Modified
- **engine/src/player.ts** — `resetForNewHand()` now sets `folded = true` for players with 0 chips, excluding them from fold-win checks and showdown
- **engine/src/game-engine.ts** — Skip dealing cards to inactive players; skip dealer button past eliminated players; skip eliminated players when finding SB/BB positions
