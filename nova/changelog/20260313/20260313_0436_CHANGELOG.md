# Fix HTML overlay positioning to use actual scene center Y — 20260313.0436

## Summary
Fixed bet input, slider panel, and history button drifting below the table on resize. The root cause was that HTML overlays used `screenHeight / 2` as the scene center, but when the viewport is taller than the scaled design height, the scene anchors to the top (`scaledH / 2`), not the screen center. Now `layoutScene()` passes the actual `currentScene.y` (scene center Y) through to all overlay positioning code.

## Files Changed

### Modified
- **miko-ui/src/main.ts** — Pass `currentScene.y` (actual scene center) instead of raw screen height to `onResize()`
- **miko-ui/src/scenes/GameScene.ts** — Updated `onResize()` to receive `sceneCenterY` and use it directly instead of `screenHeight / 2`
- **miko-ui/src/managers/GameManager.ts** — Updated `onResize()` param name to `sceneCenterY`, passed through to HandHistory
- **miko-ui/src/components/HandHistory.ts** — Updated `updatePosition()` to use `sceneCenterY` directly as `cy` instead of `screenHeight / 2`
