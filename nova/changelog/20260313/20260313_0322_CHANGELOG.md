# Auto-run board when only one player can act against all-in opponents — 20260313.0322

## Summary
When all opponents are all-in and only the human (or one AI) can still act, the board now auto-runs to showdown instead of prompting for checks each street. Also ensured the "ALL IN" label displays on all all-in players' slots when entering auto-run, and when a blind post puts a short-stacked player all-in.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Changed auto-run condition from `canActPlayers.length === 0` to `canActPlayers.length <= 1` in both `advanceGame()` and `onPlayerAction()`; added ALL IN label loop for all all-in players on auto-run entry; added `actionBar.hide()` on auto-run; added all-in check in `onBlindPosted()`
