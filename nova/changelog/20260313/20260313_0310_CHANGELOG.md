# Fix side pot logic — 20260313.0310

## Summary
Rewrote side pot implementation in the engine. The old `collectBets` tried to incrementally build side pots per-street, but had multiple bugs: eligibility mixed per-street `bet` with cross-hand `totalBet`, the main-vs-side-pot decision was flawed, `awardPots` ignored eligibility for the main pot, and remainders from integer division were lost.

New approach: `collectBets` now simply accumulates all bets into the main pot each street. At award time, `awardPots` rebuilds layered pots from each player's `totalBet` (total contribution across the entire hand). Each layer is awarded separately to the best hand among eligible non-folded players, with proper remainder distribution.

## Files Changed

### Modified
- **engine/src/pot.ts** — Simplified `collectBets` to just accumulate into mainPot; removed `collectBetsSimple` (now redundant); rewrote `awardPots` with layered pot algorithm based on `totalBet`
