# Fix pot label showing $0 during all-in runout — 20260313.0455

## Summary
Fixed the pot label dropping to $0 when a player goes all-in. The root cause: `forceHandComplete()` calls `collectBets()` then `awardPots()` which resets the engine pot to 0. Any subsequent `updatePotLabel()` call (from `pot_updated` events or street change handlers) would query the now-empty engine pot and display $0. Fixed by: (1) snapshotting the pot total before `forceHandComplete()` and displaying that frozen value, and (2) skipping all `updatePotLabel()` calls while `allInRunout` is true so the frozen label isn't overwritten.
