# Hand history log with scrollable overlay — 20260313.0242

## Summary
Added a scrollable hand history panel that displays the last 100 hand results (e.g. "JohnnyFive wins $150! — Two Pair (AAKKT)"). The panel is an HTML overlay positioned in the bottom-left above the status messages, with newest results at the top. Clears on game restart. Also includes layout tweaks: community cards moved down 5px, side seat action labels down 3px, bottom seat labels down 3px.
