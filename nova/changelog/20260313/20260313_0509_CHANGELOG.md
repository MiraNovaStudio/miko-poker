# Add table selection setting — 20260313.0509

## Summary
Added a Table setting in the Settings modal allowing the player to choose between Table 1 (default) and Table 2 backgrounds. The selection is persisted in localStorage and applies immediately without restarting. Also refactored SettingsManager.onChange to support multiple listeners instead of a single callback, fixing a bug where GameManager and GameScene would clobber each other's onChange handler.

## Files Changed

### Modified
- **miko-ui/src/managers/SettingsManager.ts** — Added `TableStyle` type and `tableStyle` property with localStorage persistence; changed `_onChange` from single callback to listener array
- **miko-ui/src/managers/AssetManager.ts** — Added `table2` asset to the manifest
- **miko-ui/src/scenes/GameScene.ts** — Store table sprite reference; swap texture on settings change via `updateTableTexture()`; import SettingsManager
- **miko-ui/src/main.ts** — Added Table 1/Table 2 button wiring and `updateTableButtons()`
- **miko-ui/index.html** — Added Table setting row with Table 1 / Table 2 toggle buttons
