# Add 4-Color Deck option for Unicode deck — 20260313.0415

## Summary
Added a 4-Color Deck setting that changes Unicode card suit colors to the standard 4-color scheme: red hearts, black spades, green clubs, blue diamonds. The option appears in the Settings modal below "Card Deck" and is only available when the Unicode deck is selected — it is visually disabled (grayed out, non-interactive) when PNG deck is active. The setting is persisted in localStorage.

## Files Changed

### Modified
- **miko-ui/src/managers/SettingsManager.ts** — Added `fourColorDeck` boolean setting with localStorage key `miko_fourColorDeck`, getter/setter with persistence
- **miko-ui/src/components/Card.ts** — Added `SUIT_COLORS_4` color map (hearts=red, diamonds=blue, clubs=green, spades=black); `drawUnicodeFace()` picks color map based on `fourColorDeck` setting
- **miko-ui/index.html** — Added "4-Color Deck" setting row with On/Off toggle buttons, placed between Card Deck and Chip Display rows
- **miko-ui/src/main.ts** — Wired 4-Color Deck toggle buttons, syncs with SettingsManager; deck type change disables/enables the 4-color row and auto-disables when switching to PNG
