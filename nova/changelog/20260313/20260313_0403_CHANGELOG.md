# Fix side pot algorithm: peel layers correctly, skip unmatched bets — 20260313.0403

## Summary
Rewrote side pot computation to match standard poker rules:

1. **Peel smallest contribution layer by layer** — Sort contributors by totalBet, deduplicate levels, build pot = increment × number of contributors at each level. This correctly handles A=100, B=50, C=25 → Main $75 (A,B,C) + SP1 $50 (A,B).

2. **Skip unmatched bets** — If only 1 contributor remains at a level, those chips are returned (not a pot). Previously showed these as a side pot, inflating the display.

3. **Show "Main:" label** — When side pots exist, display "Main: $X" + "SP1: $Y" stacked vertically instead of "Pot: total + SP inline". When no side pots, show "Pot: $total" as before.
