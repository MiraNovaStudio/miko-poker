# Fix side pot display and per-player pot distribution — 20260313.0355

## Summary
Fixed side pot tracking and display so players only win pots they're eligible for. Previously, side pots were never shown during play (the engine's `getSidePots()` was always empty because pots were only computed at award time), and the UI divided the total pot equally among winners regardless of contribution.

Changes:
1. **Side pot display during play** — Added `computeSidePots()` helper that builds layered pots from player `totalBet` values using the standard algorithm (sort by contribution, build pot layers). `updatePotLabel()` now uses this instead of the always-empty `engine.getSidePots()`.
2. **Accurate per-player winnings** — Added `handStartChips` snapshot at hand start. At showdown, actual winnings are computed from chip deltas (`postChips - (startChips - totalBet)`) instead of naively dividing the total pot by winner count.
3. **Per-winner animation** — Each winner's floating label now shows their actual winnings (`+$X`) instead of the total pot text. Multiple winners are staggered by 600ms.
4. **Status message** — Shows per-player winnings (e.g., "Player wins $200, AI wins $400") instead of one total.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `handStartChips` field, `computeSidePots()` method; rewrote `updatePotLabel()`, `onHandComplete()`, and `animatePotToWinners()` for correct side pot handling
