# Add Check/Fold preaction button — 20260313.0450

## Summary
Added a preaction button that appears while AI players are thinking, allowing the human player to pre-select Check/Fold or Fold. The button is styled like the existing action buttons and positioned at the Fold button location (x=240). It includes a checkbox indicator that fills when activated; clicking again deactivates it. When it becomes the player's turn, the preaction auto-executes: Check/Fold will check if possible, otherwise fold. The label dynamically shows "Check/Fold" when no outstanding bet exists, or "Fold" when there's already action ahead. Preaction clears on street changes and new hands.
