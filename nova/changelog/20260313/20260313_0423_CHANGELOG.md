# Fix side pot display with single all-in player — 20260313.0423

## Summary
Fixed bug where a single all-in player caused two pots to display (e.g., "Main: $50, SP1: $168"). The computeSidePots() algorithm was splitting at every distinct totalBet level instead of only at all-in player contribution levels. Rewrote the algorithm to only create pot boundaries at all-in totalBet thresholds, with one combined side pot for bets above the highest all-in level.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Rewrote computeSidePots() to only split at all-in player totalBet levels; everything above the highest all-in level merges into a single side pot
