# Return uncalled bets before proceeding to next street — 20260313.0409

## Summary
Fixed a core poker rule violation: when a player goes all-in for more than any opponent can match, the unmatched portion must be returned immediately — not held in the pot until showdown.

Example: Player A (5000 chips) goes all-in, Player B (1000 chips) calls. Previously the pot showed 6000 and A showed 0 chips. Now: 4000 is returned to A's stack immediately, pot correctly shows 2000, and the board runs out.

The fix is in `PotManager.collectBets()` which is the common path for both normal street endings and `forceHandComplete()`. Before collecting bets into the pot, it checks if one player bet more than the second-highest active bet. If so, the excess is returned: chips added back, bet/totalBet reduced, and allIn flag cleared if the player now has chips.

Also updated the UI to refresh chip labels and pot display right after `forceHandComplete()` so the return is visible before the board animation starts.
