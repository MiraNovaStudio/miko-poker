# Scale HTML overlays with viewport and add mobile gate — 20260313.0432

## Summary
Fixed the slider panel and bet input losing their relative position when resizing the browser. The slider panel now scales via CSS `transform: scale()` to match the scene scale factor, and the bet input font size scales proportionally. Added a mobile gate overlay that displays "MikoPoker is not yet supported on mobile" when the viewport is less than 500px wide, hiding all game content. This applies to both the start screen and game screen, and restores properly when resizing back above the breakpoint.

## Files Changed

### Modified
- **miko-ui/src/components/ActionBar.ts** — Added CSS `transform: scale(factor)` with `transform-origin: top left` to slider panel in `updateInputPosition()`; scaled bet input font size
- **miko-ui/index.html** — Added `#mobile-gate` CSS styles and HTML overlay element with "not supported on mobile" message
- **miko-ui/src/main.ts** — Added `updateMobileGate()` function that shows/hides the mobile gate at 500px breakpoint; added `activeScreen` tracker and `restoreUIForScreen()` to properly restore UI elements when resizing back from mobile; integrated mobile check into `layoutScene()`
