# Bet input supports BB mode with decimal values — 20260313.0209

## Summary
The bet input box now works correctly in "View Chips as BB" mode. Users can type decimal BB values like `2.5` (which converts to $25 at $10 BB). The input allows decimal points in BB mode, the placeholder shows the min amount in BB format (e.g. "2 BB"), and the inputMode switches to `decimal` for mobile keyboards.

## Files Changed

### Modified
- **miko-ui/src/components/ActionBar.ts** — Imported SettingsManager and formatChips; `getBetAmount()` converts BB input to dollars via `Math.round(bbVal * BIG_BLIND)`; `setMinBet()` uses `formatChips()` for BB-aware placeholder; `show()` sets `inputMode` to decimal/numeric based on chip display; input filter allows decimal point in BB mode
