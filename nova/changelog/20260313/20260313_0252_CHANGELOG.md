# Rebuy and Quit buttons on game-over modal — 20260313.0252

## Summary
When the player is eliminated, the game-over modal now shows "Rebuy ($1000)" and "Quit" buttons instead of "New Game". Rebuy gives the player a $1000 starting stack and continues the current game. Quit returns to the start screen. When the player wins (all opponents eliminated), only "New Game" is shown.
