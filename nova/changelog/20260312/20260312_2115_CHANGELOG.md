# Delay clearing action labels on street change so last action is visible — 20260312.2115

## Summary
Fixed last player's action label (e.g., "ai7 call $20") being cleared instantly when a new street begins. Added a `streetJustChanged` flag that pauses `advanceGame` for 1 second after a street change, and delayed `clearBet()` by 1 second in `onStreetChanged`. This ensures the last action of the previous round stays visible before the board clears for the new street. No race condition because `advanceGame` won't process the next player until after the bets are cleared.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `streetJustChanged` flag; `advanceGame()` waits 1s when flag is set; `onStreetChanged()` delays `clearBet()` by 1s instead of clearing immediately.
