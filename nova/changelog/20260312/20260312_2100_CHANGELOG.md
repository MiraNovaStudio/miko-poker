# Fix default raise to be exactly 2x the current bet — 20260312.2100

## Summary
Fixed the default raise amount when the bet input is empty. Previously used the engine's `minRaiseAmount` which factors in escalating raise sizes from prior raises. Now uses exactly 2x the current bet (player's existing bet + call amount), matching standard poker min-raise behavior.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — `onBetOrRaise()` computes `currentBet` from player state and uses `currentBet * 2` as default raise amount
