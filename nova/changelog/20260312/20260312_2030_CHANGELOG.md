# Empty raise box defaults to min raise instead of big blind — 20260312.2030

## Summary
When the bet input box is empty and the player clicks Raise, the default amount is now the minimum raise (double the current bet) from the engine's `minRaiseAmount`, instead of always defaulting to the big blind. Bet still defaults to big blind when the box is empty.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — `onMiddleButtonClick()` uses `gameState.minRaiseAmount` as default for raise, `GAME_CONFIG.bigBlind` for bet

## Test results
