# Sequential all-in board reveal and knockout animation — 20260312.2335

## Summary
When all remaining players are all-in, community cards now reveal sequentially (flop → turn → river) with 2-second delays between each street, instead of appearing all at once. Hole cards are revealed face-up before the runout begins. After the final card, a "KNOCKED OUT" animation (red text with shake effect) appears on eliminated players' card areas.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — All-in detection moved to `onPlayerAction` (engine calls `forceHandComplete` inside `processAction` before `advanceGame` can check); sets `allInRunout` flag so `onStreetChanged` queues events; `onHandComplete` defers result and kicks off `processStreetQueue()` via setTimeout(0); queue replays streets with 2s delays; hole cards revealed before runout; eliminated players get `showKnockedOutLabel()` instead of static status
- **miko-ui/src/components/PlayerSlot.ts** — Added `showKnockedOutLabel()` method: animated red "KNOCKED OUT" text with shake effect and scale-up animation, auto-hides after 7 seconds
