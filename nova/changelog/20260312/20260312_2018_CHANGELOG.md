# Remove music, convert sound button to mute toggle — 20260312.2018

## Summary
Removed background music loading and playback entirely. Converted the sound button from a music toggle to a mute/unmute toggle for sound effects. Button is unmuted by default (speaker icon), hidden on the start screen, and shown only on the game screen.

## Files Changed

### Modified
- **miko-ui/src/managers/AudioManager.ts** — Removed music buffer loading, `playMusic()`, `stopMusic()`, and `musicPlaying`. Added `muted` property (default false) that gates all `play()` calls.
- **miko-ui/src/main.ts** — Changed button from `music-toggle` to `sound-toggle`. Toggles `audio.muted` instead of play/stop music. Button hidden on start screen, shown on game screen.
- **miko-ui/index.html** — Renamed `#music-toggle` to `#sound-toggle`, default icon is unmuted speaker, `display: none` by default, title "Toggle sound".

## Test results
- Engine unchanged, no tests affected.
