# Chip display setting: Dollars or Big Blinds — 20260312.2345

## Summary
Added a settings option to show chip amounts as big blinds (BB) instead of dollars. When "Big Blinds (BB)" is selected, all chip stacks, bets, pot amounts, and status messages show values like "100 BB" instead of "$1000". The preference persists in localStorage. Switching updates all visible labels immediately.

## Files Changed

### Modified
- **miko-ui/src/managers/SettingsManager.ts** — Added `ChipDisplay` type (`'dollar' | 'bb'`), `chipDisplay` getter/setter with localStorage persistence (key: `miko_chipDisplay`); added `formatChips(amount)` helper that formats as `$X` or `X BB` based on setting
- **miko-ui/src/components/PlayerSlot.ts** — `setChips()`, `setBet()`, and `animateChipsTo()` now use `formatChips()` instead of hardcoded `$` prefix
- **miko-ui/src/managers/GameManager.ts** — All chip formatting (`onBlindPosted`, `onPlayerAction`, `onHandComplete`, `updatePotLabel`) now uses `formatChips()`; settings onChange handler refreshes chip labels and pot on change
- **miko-ui/index.html** — Added "Chip Display" row with Dollars/Big Blinds toggle buttons
- **miko-ui/src/main.ts** — Wired chip display buttons to SettingsManager
