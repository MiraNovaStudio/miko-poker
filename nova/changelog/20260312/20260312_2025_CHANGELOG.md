# Per-seat dealer button positioning to stay on the table — 20260312.2025

## Summary
Replaced the single fixed dealer button offset with per-seat offsets that point inward toward the table center. The dealer button now stays visually on the table for all 8 seat positions instead of floating off the edge for some seats.

## Files Changed

### Modified
- **miko-ui/src/utils/constants.ts** — Replaced `DEALER_BUTTON_OFFSET` with `DEALER_BUTTON_OFFSETS[]` array (8 entries, one per seat)
- **miko-ui/src/components/DealerButton.ts** — `positionAt()` now accepts optional `seatIndex` param and uses per-seat offsets
- **miko-ui/src/managers/GameManager.ts** — Passes `gameState.dealerIndex` to `positionAt()`
