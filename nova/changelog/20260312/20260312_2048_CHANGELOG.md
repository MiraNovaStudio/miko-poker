# Fix chip count animation not triggering for AI winners — 20260312.2048

## Summary
Fixed intermittent bug where the chip stack count-up animation wouldn't play for AI winners when the pot label arrived. The issue was that post-win chip values were being re-read from the engine 1.4 seconds later inside the animation callback, by which time the engine state could have changed. Now all chip values (pre-win and post-win) are captured upfront at hand completion time and passed directly to the animation.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Capture `postWinChips` map alongside `preWinChips` at hand completion. Pass both maps to `animatePotToWinners()`. Animation callback now reads from the pre-captured map instead of re-querying the engine.

## Test results
- Engine unchanged, no tests affected.
