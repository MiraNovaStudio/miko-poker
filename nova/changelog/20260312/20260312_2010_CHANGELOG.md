# Slower pot animation, deferred chip update with count-up, pot amount in status — 20260312.2010

## Summary
Slowed pot-to-winner fly animation from 800ms to 1400ms. Pot label is now hidden after animation starts and only reappears next hand. Player chip stacks are not updated until the pot arrives, then animate spinning up from old to new amount (1s ease-out). Status message now shows the pot amount won (e.g., "ai3 wins $120! — Two Pair").

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — `onHandComplete()` defers chip label updates, snapshots pre-win chip amounts, includes pot amount in status message. `animatePotToWinners()` slowed to 1400ms, clears pot label, triggers `animateChipsTo()` on arrival.
- **miko-ui/src/components/PlayerSlot.ts** — Added `animateChipsTo(from, to)` that animates chip count spinning up with ease-out over 1s.

## Test results
- Engine unchanged, no tests affected.
