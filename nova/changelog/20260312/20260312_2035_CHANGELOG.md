# Add settings button and modal with deck type option — 20260312.2035

## Summary
Added a settings gear button next to the sound button in the top-right corner. Clicking it opens a modal with a card deck selector (PNG / Unicode). PNG is selected by default. Both buttons are hidden on the start screen and shown on the game screen. Created SettingsManager singleton to store preferences.

## Files Changed

### Added
- **miko-ui/src/managers/SettingsManager.ts** — Singleton settings store with `deckType` property ('png' | 'unicode')

### Modified
- **miko-ui/index.html** — Added settings button, settings modal with deck type selector, shared `.top-btn` class for top-right buttons
- **miko-ui/src/main.ts** — Imported SettingsManager, wired settings button/modal open/close, deck type selection, show/hide with scene transitions
