# Music toggle as persistent HTML button — 20260312.1859

## Summary
Moved the music toggle from a PixiJS canvas element to a fixed HTML button in the top-right corner of the viewport. The button persists across scene transitions (start screen → game table). AudioManager is now a singleton shared between scenes instead of each scene creating its own instance. Music remains muted by default.

## Files Changed

### Modified
- **miko-ui/index.html** — Added `#music-toggle` button element with fixed positioning (top: 12px, right: 12px, z-index: 100)
- **miko-ui/src/main.ts** — Imports AudioManager singleton, initializes it once, wires the HTML music button click handler
- **miko-ui/src/managers/AudioManager.ts** — Added singleton pattern (`static instance`), added `musicPlaying` state tracking on play/stop
- **miko-ui/src/scenes/StartScene.ts** — Removed AudioManager ownership and PixiJS music button; scene is now audio-free
- **miko-ui/src/scenes/GameScene.ts** — Uses `AudioManager.instance` instead of creating a new AudioManager; removed async init wrapper since audio is pre-initialized by main.ts
