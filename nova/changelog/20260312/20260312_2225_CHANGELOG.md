# Fix default raise amount using engine's minRaiseAmount — 20260312.2225

## Summary
Fixed bug where clicking Raise with an empty bet input would default to 2x the current bet-to-call instead of the minimum legal raise. For example, if an AI raised to $23, the default was $46 (2x23) instead of the correct minimum raise ($36). Now uses the engine's `minRaiseAmount` which correctly accounts for previous raise sizes.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — `onBetOrRaise()` now uses `gameState.minRaiseAmount` for raises and `gameState.minBetAmount` for bets instead of manually calculating `currentBet * 2`

## Test results
- Engine unchanged, no tests affected.
