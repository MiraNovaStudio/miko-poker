# Rewrite AI system with 4 playstyles, remove difficulty levels — 20260312.2310

## Summary
Replaced the old difficulty-based AI system (easy/normal/hard/pro) with 4 distinct playstyles that control actual gameplay behavior:
- **Passive (40%)** — calling stations, wide VPIP (~35%), rarely raises, calls almost everything above threshold
- **Nit (15%)** — rocks, tight VPIP (~65%), only enters with premiums, folds a lot
- **Shark (25%)** — tight-aggressive, selective entry (~50%) but bets and raises hard
- **Maniac (20%)** — 50%+ VPIP (~25% threshold), bluffs constantly, raises with mediocre hands

AIConfig now has meaningful fields: vpipThreshold, aggression, bluffFrequency, callThreshold, valueBetThreshold. The preflop and postflop decision code directly uses these thresholds with playstyle-specific behaviors (e.g., maniacs call with garbage, passives never fold cheap, nits fold marginal hands).
