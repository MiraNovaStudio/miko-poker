# Unicode deck implementation — 20260312.2230

## Summary
Implemented the Unicode card deck as an alternative to PNG images. Cards render with a bold rank in the top-left, a small suit symbol below it, and a large suit symbol in the bottom-right. Hearts and diamonds are red, clubs and spades are black. Card backs use a blue design with a decorative diamond pattern. The deck type can be switched dynamically via the Settings menu — all visible cards refresh instantly.

## Files Changed

### Modified
- **miko-ui/src/components/Card.ts** — Added full Unicode rendering path: `drawUnicodeFace()` draws rounded-rect card with rank + suit text labels; `drawUnicodeBack()` draws blue card back with diamond pattern; `refresh()` method for live switching; checks `SettingsManager.deckType` in `updateDisplay()`
- **miko-ui/src/managers/SettingsManager.ts** — Changed `deckType` to getter/setter pattern with `onChange()` callback registration for live switching
- **miko-ui/src/managers/GameManager.ts** — Added `refreshAllCards()` that recursively walks all Card instances in slots and community cards; registered `SettingsManager.onChange` listener
