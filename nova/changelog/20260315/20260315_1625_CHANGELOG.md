# Fix WINNER label shown on side pot recipients — 20260315.1625

## Summary
Fixed a bug where the "WINNER!" label was displayed on all players who received any chip winnings, including side pot recipients with weaker hands. Now only the player(s) with the actual best hand get the "WINNER!" banner. Chip animations still correctly fly to all players who received winnings.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Changed `highlightWinnerNames()` to use `result.winners` (best hand only) instead of `allWinners` (everyone who got chips). Moved `allWinners` computation to only be used for pot animation.
