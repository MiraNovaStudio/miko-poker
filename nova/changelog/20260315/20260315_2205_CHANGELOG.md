# Clear ALL-IN label on winners before pot animation — 20260315.2205

## Summary
Fixed a visual bug where a player who went all-in and won the pot would keep the red "ALL IN" chip box during the pot shipping animation. The all-in state is now cleared on all pot winners before the chip-fly animation begins, restoring the normal yellow chip display style.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `clearAllIn()` call for all winner slots in `onHandComplete()`, before the pot display section. Handles both single-pot and multi-pot (side pot) winners.
