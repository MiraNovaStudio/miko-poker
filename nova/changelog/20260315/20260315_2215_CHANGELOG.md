# Fix pot shipping multiple times on normal hands — 20260315.2215

## Summary
Fixed a bug where normal hands (no real side pots) would trigger the sequential pot award animation, making it look like the pot was shipped multiple times. The cause: folded players who contributed to the pot (e.g., blinds) created separate contribution layers in the pot manager. Even though the same player won every layer, the engine reported multiple pot results, and the UI displayed each one sequentially.

The fix adds a `hasDistinctWinners()` check — `potResults` is only populated when at least two pot layers have different winners. When all layers have the same winner (which is the common case for normal hands with folded blind contributors), the hand is treated as a single pot.

## Files Changed

### Modified
- **engine/src/game-engine.ts** — Added `hasDistinctWinners()` static method; `potResults` in `GameResult` is now only set when pot layers have genuinely different winner sets.
