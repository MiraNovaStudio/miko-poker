# Add background music player — 20260315.2242

## Summary
Added a "Play Music / Stop Music" button in the upper right (to the left of the Settings button). Plays a shuffled playlist of 20 tracks from `static/assets/music/`. Tracks auto-advance when finished and reshuffle on loop. The global mute button mutes both sound effects and music; unmuting resumes music if it was playing.

## Files Changed

### Modified
- **miko-ui/src/managers/AudioManager.ts** — Added music playback: `playMusic()`, `stopMusic()`, `toggleMusic()`, `setMuted()`, shuffled playlist, auto-advance via `<audio>` element. Music pauses on mute, resumes on unmute.
- **miko-ui/index.html** — Added `#music-toggle` button in upper right.
- **miko-ui/src/styles.css** — Styled `#music-toggle` at `right: 116px` with auto width for text label.
- **miko-ui/src/main.ts** — Wired up music button click handler, mute integration via `setMuted()`, show/hide with other top buttons across all screen transitions.
