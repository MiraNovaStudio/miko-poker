# Session Changes — 20260324.0009

## Summary
Multiple improvements to side pot awards, pot display, game menu, debug tools, and showdown flow across a long session.

## Changes

### Progressive Card Reveal for Side Pots
- Multi-pot showdowns no longer reveal all cards upfront. Cards are revealed per pot — side pot eligible players' cards shown first, main pot players revealed last.
- Winning board + hole cards highlighted per pot award (not just the final pot).
- Side pot losers with 0 chips are knocked out immediately after losing their pot.

### Deferred Pot Display with Bet-to-Pot Fly Animation
- Pot label now only updates at end of each betting round, not after every bet.
- Bet labels animate flying from player slots into the pot chip area when a street ends.
- Pot label animates counting up from old to new total (800ms ease-out).
- Side pots computed and displayed only after betting completes, not in real time.
- Showdown has its own flow: bets fly in → pot counts up → 900ms pause → awards begin.
- All-in runout manages pot display independently.

### Pot Eligibility Dots
- Color-coded dots on pot labels and player slots showing who is eligible for each pot.
- Main pot dot changed from green to white.
- Dots bold (enlarge) during pot award animation.
- Dots removed per-pot by color (not by position) so main-only players keep their dot.
- Pot label dot also bolds during award.
- Dots only shown when side pots exist.

### Game Menu (Escape / MikoPoker Title)
- Replaced About modal with game menu: Resume, New Game, Quit Game.
- Escape key and MikoPoker title click toggle the menu.
- P key closes menu if open.
- pause() and unpause() made public on GameManager.

### Debug Tools
- `debugHandLog(n)` now works for the current hand in progress.
- `debugSidePots(4)` added (6 players, 4 side pots).
- `debugSidePots(n)` from idle state resets all players, avatars, chips, and starts immediately.
- Side pot debug suppresses game-over; can re-run repeatedly.
- `debugHideCards()` now toggles (show/restore cards).
- Fixed stale pause queue causing errors on New Game from menu.
- Fixed `potChips` not cleared on restart.

### Action Bar Fixes
- Raise amount placeholder capped at player's remaining chips (not chips + current bet).
- Clamp check in onBetOrRaise uses capped min amount (prevents jumping to raw engine min).
- Auto-clamp flashes input red when bet is too high or too low.
- BB "Check" label now flies a chip into pot (tracked via playersWithBetsThisRound set).
- Last action label visible before showdown (800ms defer for all hand completions).
- Slider panel position refreshed via resize event on show().

### Audio
- Button award sound: floraphonic-90s-game-ui-6-185099.mp3
- Fireworks loop: freesound_community-fireworks-generated-31449.mp3 (plays 2s after victory, loops at 40% volume, stops on dismiss).

### Bug Fixes
- Side pots preserved during award animation (setPotWithDots instead of plain setPot).
- Pot count animation skipped for side pot display (prevents overwriting dot labels).
- Showdown pot display built from result data (engine pot is 0 after award).
- Community cards from previous hand no longer shown on new hand (handCounter guard).
- All-in runout clears playersWithBetsThisRound (no phantom chip flies).
- MikoPoker KO win no longer shows "Keep Playing" button.
