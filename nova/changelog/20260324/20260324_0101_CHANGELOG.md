# Session Changes (continued) — 20260324.0101

## Summary
Continued improvements to showdown flow, hand history, action feedback, audio, and game-over UI.

## Changes

### Showdown Flow — Single Pot Speedup
- Single-pot showdown no longer flies bets to the pot then pot to winner (two-step). Bets on the table now fly directly to the winner alongside the pot chips — one step, much faster.
- Side pot showdowns still fly bets to pot first (needed to show pot breakdown before sequential awards).

### Progressive Card Reveal — Hand Name Display
- WINNER label now shows hand strength above ("Trip 8's") and pot type below ("Side Pot"), matching the normal showdown layout.
- Winning board + hole cards highlighted per pot award (not just the final pot).
- Uses `getDetailedHandName` for consistent naming (Trip, Set, Quad, etc.).

### Hand History — Losing Hands
- Losing hands now logged before winner entries: "Hand 001: LuckyRiver shows — Two Pair (KKTT9)".
- Added `getPlayerHandSummary()` and `getHandDescriptionFromStrength()` helpers for compact hand descriptions.
- Works for both single-pot and multi-pot (per-pot losers logged before each pot winner).

### Action Flash in Stack Box — Fixed
- Call/Bet/Raise/Fold flash in chip overlay was broken — `pot_updated` event's `updateAllChipLabels()` immediately overwrote the flash text.
- Fixed: `setChips()` now skips update when a flash timer is active.

### Fold with Outstanding Bet
- When a player folds with chips already on the table, the bet label stays showing the amount in gray (fold color) instead of replacing with "Fold" text.
- "Fold" flashes in the chip overlay for 2 seconds then restores the chip count.
- Chips from folded players still fly into pot at round end via `playersWithBetsThisRound` tracking.

### Chips Collect Sound
- Added `freesound_community-poker_chips1-87592.mp3` — plays when bets fly from table into pot chip area.

### Game Over — Quit + Keep Playing for MikoPoker KO
- Quit button now shows on ALL game-over screens (not just player elimination).
- Keep Playing shows for MikoPoker KO if there are still AI players available in the roster.
- Only hidden when entire roster is exhausted.
