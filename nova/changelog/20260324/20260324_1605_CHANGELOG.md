# Add SVG deck, 4-color SVG support, and layout improvements — 20260324.1605

## Summary
Added SVG as a third card deck option alongside PNG and Unicode. Implemented 4-color deck support for SVG cards by fetching SVG text at runtime and recoloring diamonds (blue) and clubs (green) to match the Unicode 4-color scheme. Changed Card Deck and Chip Display settings rows to stack options vertically. Fixed blank card issue when toggling 4-color by switching from blob URLs to data URLs for recolored SVGs. Set SVG card padding background to pure white (#FFFFFF) to match the SVG card backgrounds.

## Files Changed

### Modified
- **miko-ui/src/managers/SettingsManager.ts** — Extended `DeckType` to include `'svg'`
- **miko-ui/src/managers/AssetManager.ts** — Added `loadCardSvgs()`, `loadCardSvgs4Color()`, and `getSvgCardTexture()` with 4-color support using runtime SVG recoloring via data URLs
- **miko-ui/src/components/Card.ts** — Added SVG rendering branch with pure white (#FFFFFF) rounded-rect background and inset sprite; passes fourColor flag for SVG texture lookup
- **miko-ui/index.html** — Added SVG button to Card Deck row, applied `setting-options-vertical` class to Card Deck and Chip Display rows
- **miko-ui/src/styles.css** — Added `.setting-options-vertical` class for vertical button stacking
- **miko-ui/src/main.ts** — Wired up SVG deck button and 4-color SVG loading; enabled 4-Color Deck toggle for both Unicode and SVG modes
