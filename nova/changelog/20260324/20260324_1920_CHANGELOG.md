# Side Pot & Card Highlight Fixes — 20260324.1920

## Summary
Fixed two issues with multi-pot hands:
1. Winning cards were pushed up (-25px) once per pot award, stacking the offset when the same player won multiple pots. Now tracks highlighted players and only pushes cards up once.
2. Replaced gray/dimmed side pot amounts with label-only display ("Main", "Side") during active betting before bets are collected. Amounts appear once bets are animated into the pot.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Added `highlightedPlayers` Set to prevent duplicate card push-ups in multi-pot awards; changed `updatePotLabel(labelsOnly)` to show label-only dot lines during active betting; removed `dimmed` parameter
- **miko-ui/src/components/StatusBar.ts** — Removed `dimmed` parameter from `setPotWithDots()`, reverted to clean original styling
