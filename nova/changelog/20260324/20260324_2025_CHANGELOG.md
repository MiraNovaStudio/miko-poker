# Consistent Showdown Hand Labels — 20260324.2025

## Summary
All showdown players now get scene-level hand name labels — winners in gold bold, losers in yellow italic. Previously, winners and eliminated players were skipped (their hand names only appeared briefly as part of the WINNER animation or bet label text that got overwritten by knockout labels). Now every player who goes to showdown has a persistent hand name visible for the full duration, regardless of winner/loser/knockout status.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Unified `showShowdownHandNames()` and `showHandNamesForPlayers()` to show scene-level labels for ALL players (winners + losers). Removed skips for `winnerSet`, `eliminatedPlayers`, and seat-based routing to bet labels. All labels now use `showWinningHandAtSlot()` or `showLosingHandAtSlot()` consistently.

## Test results
- Engine unchanged; `npx tsc --noEmit` passes clean.
