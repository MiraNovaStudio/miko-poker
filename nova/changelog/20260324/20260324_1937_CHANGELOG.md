# Side Pot Display Overhaul — 20260324.1937

## Summary
Fixed side pot display issues found during debugSidePots(2) testing:
1. **Removed premature side pot labels** — No longer show side pot labels during active betting before bets are collected. The side pot breakdown now only appears after bets are collected into the pot (on street change or all-in runout).
2. **Fixed single-eligible filter** — The previous filter incorrectly skipped middle pot layers with only 1 eligible player (which ARE real pots). Now only the top layer above the highest all-in is filtered when single-eligible (true uncalled bet). This ensures all side pots display correctly (e.g., Main + Side + Side for 4 players at different all-in amounts).
3. **Cleaned up labelsOnly code path** — Removed the unused `labelsOnly` parameter and its associated branching from `updatePotLabel()`.

## Files Changed

### Modified
- **miko-ui/src/managers/GameManager.ts** — Removed early side pot label display during active betting; reverted single-eligible filter to only apply on the top layer (uncalled bet above highest all-in); removed `labelsOnly` parameter from `updatePotLabel()`
