# Fold Win History + Version Bump — 20260324.0159

## Summary
Fixed fold win hand history showing winner's hand strength when cards weren't revealed. Version bumped to 0.6.1.

## Changes

### Fold Win History Fix
- Fold wins no longer show the winner's hand strength in the history log or status bar. Cards aren't revealed on fold wins, so showing "Pair of Fours (44Q83)" was misleading. Now just shows "UltraSage11 wins $547".
- Hand summary only displayed when `result.winningHand` is truthy (showdown occurred).

### debugHandLog Octal Warning
- Added warning when `debugHandLog(020)` is called — JS interprets `020` as octal (16). Suggests using `debugHandLog("020")` or `debugHandLog(20)` instead.

### Version Bump to 0.6.1
- Updated all three package.json files (root, engine, miko-ui) from 0.5.6 to 0.6.1.
