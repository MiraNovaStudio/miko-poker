# Session Changes (continued) — 20260324.0129

## Summary
Hand history cleanup, BB check behavior, chop pot handling, pause-aware timers, and side pot display fixes.

## Changes

### Hand History Cleanup
- No more duplicate hand entries across side pots — `loggedPlayers` set tracks who has been logged.
- All hand entries now use `getPlayerHandSummary()` which includes the 5-card breakdown (e.g. "Straight (AKQJT)" instead of just "Straight").
- Winner entries in both single and multi-pot paths show detailed hand summary.

### BB Check Behavior
- When BB checks with chips on the table, the bet label keeps showing the amount (e.g. "$10") instead of replacing with "Check".
- "Check" flashes in the chip overlay stack box for 1.5s then restores chip count.

### Chop Pot Handling
- When multiple players win a single pot, bets fly to the pot first (like side pots), then the pot distributes evenly to all winners.
- Single-winner pots still skip the bet-to-pot step (table chips fly directly to winner).

### Pause-Aware Timers
- WINNER/BUTTON/K.O. label auto-hide timers now freeze during pause via `pauseableTimeout`.
- Flash action text (Call/Raise/Fold in chip overlay) also freezes during pause.
- Winning hand name labels use `delayed()` which already pauses.
- `PlayerSlot.isPaused` static callback wired from GameManager.

### Side Pot Display Fixes
- Fixed: all-in runout with side pots now shows pot breakdown with dots (was showing plain "Pot: $X").
- Fixed: hand name on WINNER label was blank because `currentCommunityCards` was cleared too early. Now preserved until next hand starts.
